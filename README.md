## Ai-CEO

یہ ہمارا مرکزی AI CEO ہے۔

اس کا کام:
- صارف سے کام لینا
- بڑے کام کو چھوٹے کاموں میں تقسیم کرنا
- متعلقہ AI agents کو کام دینا
- ہر agent کے کام کا نتیجہ چیک کرنا
- ضرورت پڑنے پر کام دوبارہ کروانا
- آخر میں مکمل نتیجہ صارف کو دینا
